# SANKET · Workforce Command Centre

Frontend-only demo of India's AI-enabled Workforce Intelligence & Activation Engine.

## Stack

- Next.js 14 (App Router) · React · TypeScript
- Tailwind CSS · Radix/shadcn-style UI · Recharts · Leaflet
- Zustand · Framer Motion · Lucide

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo login

Any credentials work. Use **Quick demo login → Government Planner**, then follow the guided demo toggle in the header.

## Journey

Control Room → Economic Signals → Event Analysis → Capability → Worker → Transformation → Training → Activation → Scenario → Approval → Implementation → Outcomes → Evidence & Audit
